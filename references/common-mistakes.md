# 数学 / 编程典型错误与引导

本文件列出学生在数学和编程作业中最常见的错误类型，以及辅导时的引导策略。
核心原则：**指出错误的位置和类型，不给出正确结果。**

---

## 一、数学典型错误

### 代数类

| 错误 | 引导提问 |
|------|---------|
| 移项时忘记变号 | "你把这一步的代换回上一步检查一下？左边和右边还相等吗？" |
| 展开括号漏乘（如 2(x+3) 写成 2x+3） | "你把 2 乘进去时，乘了哪几项？再数一遍。" |
| 合并同类项时漏掉某系数 | "把所有 x² 项圈出来，逐个系数相加。你确定没有漏？" |
| 分式运算丢掉公分母 | "你通分了吗？找一下 LCD 是什么？" |
| 平方根只取正根 | "平方根的定义是什么？正负两个都考虑了吗？" |
| 不等式同乘负数不变号 | "乘以负数时，不等号需要做什么？回忆一下规则。" |
| 消去因子时忽略了因子可能等于零 | "你除以的这个式子等于 0 会怎样？这需要单独讨论吗？" |

### 微积分类

| 错误 | 引导提问 |
|------|---------|
| 链式法则漏掉内层导数 | "这个函数是复合的吗？外层导完了，内层的导数乘以了吗？" |
| 混淆 d/dx(sin x²) 和 d/dx(sin² x) | "这两个式子的含义不同。先确认：谁的平方？sin 的平方还是 x 的平方？" |
| 积分忘记 +C | "不定积分的定义是什么？导回去会多出什么？" |
| 换元后忘记换积分上下限 | "你换元了。原来 x 从 a 到 b，新的 u 从哪到哪？" |
| 分部积分的 u 和 dv 选反了 | "LIATE 规则：Log → Inverse trig → Algebraic → Trig → Exponential。你选的 u 在列表靠左吗？" |
| 认为 d/dx(eˣ) = xeˣ⁻¹（把 eˣ 当幂函数） | "eˣ 是指数函数还是幂函数？指数函数的导数规则是什么？" |
| 导数零点 = 极值点的充要条件不检查 | "f'(x)=0 的点一定是极值点吗？二阶导数告诉你什么？端点和间断点检查了吗？" |

### 线性代数类

| 错误 | 引导提问 |
|------|---------|
| 矩阵乘法不满足交换律却下意识交换 | "矩阵乘法中 AB 和 BA 相等吗？检查一下维度。先说能不能乘，再说结果是什么。"
| 行列式和矩阵混淆 | "det(A) 是一个数还是一个矩阵？A 的逆公式中，你写的是 1/|A| 还是 1/A？" |
| 特征向量求错（选错自由变量）| "这个方程组的自由变量是哪个？你代回去验证 Ax = λx 了吗？" |
| 判断线性无关时行列式为 0 就下结论 | "行列式为 0 说明什么？线性相关还是线性无关？" |

### 统计类

| 错误 | 引导提问 |
|------|---------|
| 混淆 population SD 和 sample SD（分母 n vs n-1）| "你计算的是总体标准差还是样本标准差？分母分别是多少？为什么差 1？" |
| 不理解 p-value（以为 p = H₀ 为真的概率） | "p-value 的定义是什么？它是在什么假设下计算的？p > 0.05 能不能说你证明 H₀ 为真？" |
| t-test 未检查 normality / homogeneity | "t-test 的假设有哪些？你的数据满足吗？不满足该用什么替代？" |
| Regression 不看 residuals | "你 plot 了 residuals 吗？有没有异方差 (heteroscedasticity)？有没有明显的 pattern？" |
| Confounding variable 未控制 | "这个相关性有没有可能是第三个变量 Z 导致的？你的模型控制了 Z 吗？" |

## 二、编程典型错误

### Python 常见错误

| 错误 | 引导提问 |
|------|---------|
| off-by-one（range(n) vs range(1, n+1)） | "Python 的 range(n) 从几到几？你要遍历多少次？在纸上数。"
| 混淆 = 和 == | "你想做赋值还是比较？这两者在 Python 里的 syntax 分别是什么？"
| list 遍历时修改 list | "你在遍历同一个 list 的同时修改它。迭代器内部的索引会怎样？应该遍历一个 copy 吗？"
| mutable default argument | "你的函数的 default 参数是 []。每次调用使用同一个 list 对象。你在 lecture 里学过这个经典陷阱吗？"|
| 字符串拼接用 + 在循环里（O(n²)）| "每次 + 都会创建新字符串。换一种方式收集所有部分一次性 join？复杂度会从什么变到什么？"
| 忘记闭包/循环中 lambda 的延迟绑定 | "lambda 里引用的变量 i，在使用时才求值。循环结束后 i 的值是什么？"
| 大文件一次性 read() | "如果文件有 10GB，read() 会怎样？应该用哪种读取方式？"
| bare except（except: 不指定异常类型）| "你这个 except 会捕获 KeyboardInterrupt 吗？是否需要精确指定你想 catch 的异常类型？"

### 算法/数据结构常见错误

| 错误 | 引导提问 |
|------|---------|
| 二分查找 mid 和 left/right 更新不正确 | "循环条件是 left < right 还是 left <= right？mid 往左还是往右取决于什么？" |
| Recursion 缺少 base case / base case 错误 | "你的递归什么时候停？base case 是什么？用 n=0 和 n=1 手动追溯第一层。"
| 递归重复计算（如朴素 Fibonacci）| "算 fib(5) 的时候，fib(3) 被算了几次？你能否缓存已计算的？"
| DP 中 dp 数组维度/初始化错误 | "dp[i] 代表什么？base case dp[0] 应该填什么？状态转移方向对吗（从小到大/从大到小）？"
| Graph 遍历时未标记 visited 导致无限循环 | "你访问过的节点标记了吗？如果是 cycle graph，你的 DFS 会停吗？"
| Heap/Priority Queue 混淆 min-heap 和 max-heap | "Python 的 heapq 是 min-heap 还是 max-heap？你要的堆顶是最小还是最大？需要取负吗？"

### 面向对象/设计常见错误

| 错误 | 引导提问 |
|------|---------|
| 忘记 self 参数（或 cls for classmethod） | "instance method 的第一个参数应该是什么？这个方法是属于实例还是属于类？"
| __init__ 中 return 了一个值 | "Python 的 constructor 能 return 吗？它实际 return 了什么？"
| 直接访问类的 mutable class variable | "这个 list 是 class variable 还是 instance variable？所有实例共享一个吗？"
| 继承时忘记 super().__init__() | "子类的 __init__ 调用父类的 __init__ 了吗？父类的属性初始化了吗？"

## 三、辅导使用方式

当学生的作业出现以上错误时：

1. 识别错误类型，但不直接说出正确答案。
2. 从表中选取对应的引导提问。
3. 如果学生不能回答引导问题 → 升一级（L2 给框架 / L3 给 #TODO）。
4. 如果学生纠正了错误 → "你做对了。能解释一下刚才错在哪里吗？这样可以避免下次再犯。"

**绝对不说**：
- "这里应该是 X，不是 Y"
- "把这一行改成这样：..."
- "正确答案是..."
